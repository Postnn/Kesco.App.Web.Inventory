# Инструкции Inventory

> Глобальные правила — в корневом `/AGENTS.md`, особенно разделы `Границы Services`, `Enum для фиксированных кодов БД` и `Employee CurrentUser и авторизация`. Доменные детали — в `src/Clayzor.Lib.Entities/AGENTS.md`.

## Формы и Services

- В каждой форме с пользователем/правами при первичной асинхронной загрузке создавать `Employee CurrentUser` до расчёта доступности. Не использовать собственные `HasRoleAsync`, `HasRoleForPersonAsync` и SQL в компоненте.
- Перед записью/внешним действием заново проверять права через `CurrentUser`; при смене владельца/лица и при прямом вызове без рендера проверка обязательна. Ошибка получения Employee или прав — fail closed.
- Не создавать CRUD-прокси. Простые CRUD и read models переносить в `Clayzor.Lib.Entities`. Сохранять пакетное чтение `QueryMultiple`, атомарный equipment/phone diff, транзакции, повтор АТС без повторного UPDATE и серверные проверки секретных endpoint.
- Services оставлять только для документированной координации составных сценариев. `PhoneFormRules` и другие чистые UI-правила размещать в `Rules`/feature-каталоге, а не в Services БД.
- Фиксированные коды заменять подтверждёнными enum из Entities, включая 42/43/44/66/68/102/103, 27/30, 55, 2365. Роль 42 не называть `Специалист_SIM` по догадке.

## Компоновка Tel и других форм

- Сохранять смысловые пары legacy и порядок Tab. При скрытии зависимого поля оставлять placeholder, чтобы остальные поля не смещались в чужие позиции. Использовать компактные общие контролы, не создавая локальных копий.
- Внешний вид и высота Clay-контролов изменяются только централизованно. Локальные CSS/inline-переопределения размеров, отступов и оформления для отдельной формы запрещены; однотипные контролы имеют одинаковую высоту на всех формах.
- Прямые `window.open` и `JS.InvokeVoidAsync("open")` запрещены. Для карточек и форм использовать только `clayOpen` с устойчивым ключом; размер/позиция сохраняются отдельно для каждой формы, родительское окно не закрывается и не перезагружается.
- Таблицы и табличные секции — только `ClayGrid`; `ClayDetailGrid`, `MudTable` и собственные `<table>` запрещены.
- Проверять сборку, профильные тесты, реальные CRUD там, где доступен тестовый стенд, popup и адаптивность 320–480px без изменения production-данных.
