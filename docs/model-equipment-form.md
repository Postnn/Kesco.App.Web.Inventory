# Модель оборудования — руководство пользователя

Форма `ModelEquipmentForm` предназначена для создания и изменения моделей оборудования.

## Открытие формы

- Новая модель: `/Equipment/ModelEquipmentForm`.
- Новая модель с заранее выбранным типом: `/Equipment/ModelEquipmentForm?codetype=5`.
  Также поддерживается legacy-параметр `_codetype`; если заданы оба, приоритет у `_codetype`.
- Существующая модель: `/Equipment/ModelEquipmentForm?id=123`.

Для новой записи отображается заголовок «Новая модель оборудования». После первого
применения в адрес добавляется полученный `id`, и форма переходит в режим редактирования.

## Кнопки формы

- **OK** — сохраняет изменения и закрывает форму. Если изменений нет, просто закрывает её.
- **Применить** — сохраняет изменения и оставляет форму открытой.
- **Обновить** — повторно загружает запись. Несохранённые изменения требуют подтверждения отмены.
- **Отмена** — закрывает форму; при наличии изменений запрашивает подтверждение.

При закрытии или переходе на другую страницу несохранённые изменения не теряются молча:
форма показывает подтверждение.

## Заполнение полей

| Поле | Как заполнять |
|---|---|
| Тип оборудования | Обязательное поле. Введите часть названия и нажмите Enter либо кнопку «…». Флажок под полем переключает сортировку списка между идентификатором и алфавитом. |
| Модель | Обязательное наименование, до 100 символов. Пара «модель + PN» должна быть уникальной. |
| Ресурс | Необязательный ресурс из базы справочников. Обычный поиск доступен всегда; расширенный поиск, создание и просмотр карточки доступны при настроенных `URI_resource_search` и `URI_resource_form`. |
| PN | Part Number, до 50 символов. Для типов 1 и 2 требуется не менее 3 символов. |
| Размер монитора | Число с одним знаком после запятой. Поле доступно только для типов с характеристиками монитора; ноль отображается как пустое значение. |
| Мультимедиа | Флажок для типов с характеристиками монитора или компьютера. |
| CPU | До 50 символов; доступно для компьютерных типов. |
| Net | Количество сетевых интерфейсов от 0 до разрешённого типом максимума. При `Net=0` название Net очищается и недоступно. При `Net>0` название должно содержать не менее 3 символов. |
| Тип памяти | Список типов памяти; значение по умолчанию — пустой тип с кодом 0. |
| Банки памяти | Неотрицательное целое число. |
| Драйвер | Многострочный текст до 300 символов. |
| Срок службы | Произвольная строка до 50 символов. Это не выбранный ресурс. |
| Примечания | Многострочный текст до 300 символов. |

При смене типа поля, недоступные новому типу, автоматически очищаются. Если с моделью
связано оборудование и тип действительно меняется, перед сохранением появляется предупреждение
с общим количеством оборудования и количеством списанных единиц.

## Сохранение и ошибки

Перед записью форма проверяет обязательные поля, PN, название Net и отсутствие дубликата.
Дополнительные ограничения проверяются триггером SQL Server: права, максимальное число
сетевых интерфейсов и фактически занятые MAC-адреса у связанного оборудования.

Ошибки SQL отображаются в общем баннере `ClayErrorBar`. После исправления значения повторите
сохранение. Удаление модели в форме отсутствует.

## Права

- Изменение модели требует роли **43 — Специалист по инвентаризации оборудования**.
- Изменение шаблона телефона требует роли **102 — Дежурный инженер**.

Без роли 43 поля доступны только для чтения. Окончательная проверка прав всё равно выполняется
в базе данных.

## Шаблон телефона

Кнопка «Изменить» появляется только для существующей модели типа 30 у пользователя с ролью 102.
Она открывает отдельную форму `/Equipment/PhoneTemplateForm?id=123`.

В редакторе можно изменить текст, загрузить файл `.txt`, `.cfg` или `.xml`, применить изменения
либо сохранить и закрыть форму. Очистка непустого шаблона требует отдельного подтверждения.

## Сведения об изменении

Внизу формы редактирования находится `ClayChanged`: сотрудник и дата последнего изменения.
Эти значения заполняются триггером базы данных. Для новой записи область пуста.
