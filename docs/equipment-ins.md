# Ввод оборудования — руководство пользователя

Форма `EquipmentIns` предназначена для регистрации нового оборудования с начальным
расположением, ответственным и, при необходимости, бухгалтерским учётом.

## Открытие формы

- Новая запись: `/Equipment/EquipmentIns`.
- С предварительно выбранным типом: `/Equipment/EquipmentIns?codetype=103`.
- Копирование типа, модели, владельца и расположения: `/Equipment/EquipmentIns?copyId=123`.

Из грида 1001 форма открывается в отдельном окне. После сохранения родительский грид
обновляется без перезагрузки страницы и с сохранением фильтров и текущей страницы.

## Заполнение

1. Укажите дату и время поступления. Они вводятся во времени вашего компьютера и сохраняются
   в базе в UTC с учётом сезонного смещения на выбранную дату.
2. Выберите тип и модель. Список моделей зависит от типа. Флажок под типом переключает
   сортировку между идентификатором и алфавитом.
3. Заполните SN, если он обязателен для выбранного типа.
4. Для моделей с соответствующими характеристиками укажите сетевое имя и MAC-адреса.
   Разделители MAC удаляются автоматически; допустимы 12 шестнадцатеричных символов.
5. Выберите владельца. Документ поступления ищется с учётом связанных с ним лиц. Если среди
   лиц документа кроме владельца есть только один поставщик, он подставляется автоматически.
6. Укажите расположение и примечание. Для расположения «На руках» ответственный обязателен.
7. При необходимости выберите ответственного и добавьте примечание.
8. Если бухгалтерский блок доступен для владельца и ваших ролей, включите учёт и заполните
   инвентарный номер, документ, арендатора и примечание.

Расширенный поиск, создание и просмотр карточек справочных сущностей не отображаются,
пока соответствующие внешние URI не настроены; обычный серверный поиск доступен во всех полях.

## Кнопки

- **OK** — создаёт оборудование, обновляет родительский грид и закрывает окно. Если данных
  для сохранения нет, просто закрывает форму.
- **Применить** — создаёт оборудование и формирует переход на адрес формы редактирования
  с полученным `id`. Сама форма редактирования реализуется отдельным этапом.
- **Обновить** — заново загружает исходные значения; при наличии изменений запрашивает
  подтверждение.
- **Отмена** — закрывает форму; несохранённые изменения требуют подтверждения.

Создание выполняется одной хранимой процедурой: оборудование, начальное расположение,
ответственный и выбранный бухгалтерский учёт сохраняются атомарно. При ошибке SQL введённые
значения остаются на форме, а подробности отображаются общим баннером приложения.

## Права

Для создания требуется роль **43 — Специалист по инвентаризации оборудования**.
Бухгалтерский блок зависит от ролей **66 — Бухгалтер** и **68 — Главный Бухгалтер 1С**,
а также от ведения бухгалтерского учёта выбранным лицом.
