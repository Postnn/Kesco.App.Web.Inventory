# Редактирование оборудования

Форма открывается по адресу `/Equipment/EquipmentForm?id=<ID>`, в том числе из реестра оборудования.
После сохранения реестр обновляется в уже открытом окне без полной перезагрузки страницы.

## Панель команд

- **OK** — сохранить изменения и закрыть форму.
- **Применить** — сохранить изменения и остаться на форме.
- **Обновить** — повторно загрузить запись; при наличии изменений форма запросит подтверждение.
- **Отмена** — закрыть форму; несохранённые изменения также требуют подтверждения.
- **Копировать** — открыть форму создания с основными полями текущего оборудования. Табличные секции
  автоматически не копируются.
- **Операции** — выпадающее меню: «Подключить к UPS» открывает отдельный диалог выбора; команды
  «Подключить к локальной сети / Отключить от локальной сети» изменяют привязку к сети. Перед сетевой операцией
  основные изменения сохраняются, отключение требует подтверждения.
- **Конфигурация** — для IP-телефона открыть XML-конфигурацию в новом окне. Требуются сохранённая форма,
  MAC-адрес, телефонный пул, шаблон модели и роль 102.
- **История имён** — показать историю сетевых имён с сотрудником и локальным временем изменения.
- **Детализация** — для SIM с исполнителем «Билайн» открыть внешнюю детализацию мобильной связи через
  `clayOpen`, не закрывая форму оборудования. Перед открытием заново проверяются доступность SIM и ответственный.
  Кнопка отображается только при заданном `URI_accounting_phone_form`.

Повторное нажатие во время сохранения заблокировано. Диалоги не очищают несохранённые поля основной формы.

## Основные поля

Доступны списание и документ списания, тип и модель, серийный номер, телефонный пул, камера, сетевое имя,
MAC-адреса, владелец, документы поступления, поставщик, арендатор и примечание. Состав видимых сетевых и
специальных полей зависит от типа и модели.

При смене типа или модели скрытые пользовательские значения не очищаются автоматически. Подтверждённая очистка
типа сбрасывает модель и фильтры, а Escape восстанавливает прежний выбор. Существующие несовместимые секции
остаются видимыми только для чтения; связанные записи не удаляются. MAC можно вставлять с разделителями:
двоеточиями, дефисами, пробелами и точками.

Для большинства типов дата списания требует документ списания. Для SIM-карты действует отдельное правило без
обязательного документа. Даты и время вводятся локально, а в базу записываются в UTC с учётом часового пояса
браузера на конкретную дату, включая переходы на летнее время.

Модель можно искать без предварительного выбора типа; при выборе модели её тип устанавливается автоматически.
Под полем выводятся имеющиеся PN, мультимедиа, диагональ, CPU, сетевые интерфейсы, тип и банки памяти,
драйвер, ресурс и примечание. Арендатор доступен только для чтения.

При смене владельца обновляются фильтры документов и права, но уже выбранные документы и поставщик не очищаются
автоматически. Выбор телефонного номера учитывает расположение, сотрудника, тип, оборудование, основной номер
и номера, уже добавленные в список. Поиск документов списания ограничен типом «Акт списания оборудования» (2365).
Пока документ не выбран, подготовленные акты списания выводятся текстом с названиями, номерами и датами;
один запрос объединяет позиции и документы. Ссылка не создаётся без подтверждённого URI карточки документа.

## Права и видимость

- **Учётные записи** показываются для типа с MAC-характеристикой и роли 102; изменение требует также роль 43.
- **Подключение рабочей сети** доступно для компьютерного типа с ролью 103.
- **Подключение и изменение UPS** доступно для IT-оборудования, кроме SIM, с ролью 43 по владельцу.
  Существующие связи остаются доступными для чтения.
- **Бухгалтерский учёт** показывает разрешённые данные и без права изменения; команды зависят от бухгалтерской роли.
- **Лицензия** пересчитывает право 44 при смене владельца; существующие SIM и лицензия открываются для
  редактирования вместо повторного добавления.
- **Установленное ПО** зависит от компьютерной характеристики, а не от наличия лицензии.

## Табличные секции

Все секции используют статический `ClayGrid` без собственных заголовков и панели инструментов. Добавление
находится в шапке сервисной колонки, а редактирование, удаление и специальные действия — в ячейках этой колонки.

- **Телефоны** — компактный грид без шапки показывается только при наличии номеров и находится над полем
  выбора. Новый номер добавляется сразу после выбора в `ClaySelect`, отдельной кнопки нет. Основной номер подписан,
  просроченный срок выделяется, оборудование подключения открывается по ссылке. Ссылка на номер появляется при
  настроенном `URI_tel_form`. Для нескольких номеров в гостиничном номере выводится предупреждение. Изменения
  сохраняются вместе с основной записью одним diff; затем синхронизируются только изменённые связи.
  При ошибке АТС данные остаются сохранёнными, а повторный «Применить»/OK повторяет только синхронизацию,
  без повторного UPDATE. Переключение типа не заменяет несохранённый телефонный diff и его baseline.
- **Расположения** — история перемещений, примечания и сроки возврата. Операции с текущим периодом проверяют
  появление более поздней записи.
- **Ответственные** — назначение, изменение сроков и изъятие. Для расположения «На руках» ответственный
  обязателен; при изъятии может потребоваться новое расположение.
- **Учётные записи** — секция по умолчанию скрыта за ссылкой «Учетные записи оборудования». После нажатия
  ссылка исчезает и показывается грид. Секрет читается только отдельным авторизованным действием.
- **Компьютер** — дневные снимки с отдельными модулями RAM1…n, HD1…n и SSD1…n, стандартными
  конфигурациями с датами и лицензией. Повторное сохранение в тот же день обновляет текущий снимок.
- **SIM-карта** — номер, активация, договор и лицо персональных данных. При подтверждённом дубликате номера
  прежняя SIM списывается атомарно с сохранением текущей. PIN/PUK доступны только пользователю с ролью 42.
- **Дополнительные услуги SIM** — фактический период, код, плановые даты (если источник их возвращает),
  стоимость, история и обязательные услуги. Просроченный план и требуемое отключение помечаются предупреждением;
  активная `_BLOCK` выводит «заблокировано». Под гридом показываются итоги в день и в месяц. Тарифный план
  выделяется в списке. Проверяются границы дат и пересечения.
- **Лицензия** — тип, период, количество, дистрибутив и ссылка проверки лицензии; доступна с ролью 44 по
  владельцу или арендатору.
- **Установленное ПО** — ссылка на карточку ПО, дистрибутив, период и выделение деинсталляции.
- **Бухгалтерский учёт** — арендатор, материал, инвентарный номер, поступление, списание и примечания.
  Доступность определяется бухгалтерской функцией для владельца.
- **Маршрутизатор** — read-only описание и инвентарные модули с характеристиками.

Вспомогательные диалоги обновляют только связанную секцию. Отдельные операции UPS позволяют связать UPS,
изменить состав серверов и зарегистрировать тесты с транзакционным сохранением diff.

## Дополнительные сведения

Вверху формы строка «Подключено к: …» содержит ссылки на подключённые UPS; для пользователя с правом
управления ссылка открывает серверы и тесты соответствующего UPS. Последняя инвентаризация показывается одной
строкой сразу под гридом расположений. Блок **Changed** показывает сотрудника и локальное время изменения.

## Ограничения текущего стенда

- WakeOnLan не exposed: в базе `Инвентаризация` отсутствует требуемая процедура `sp_WakeOnlan`. Кнопка не
  имитирует включение устройства.
- Внешняя детализация мобильной связи не подключена: не задан `URI_accounting_phone_form`, а приложение
  тарификации на стенде отсутствует. Остальные операции SIM работают напрямую с базой инвентаризации.
